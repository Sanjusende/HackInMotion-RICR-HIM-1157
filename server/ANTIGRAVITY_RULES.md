 # Smart Farm Backend Rules

1. Use MVC + Services architecture.

2. Never create duplicate files.

3. Never modify API response structure without approval.

4. Use async/await everywhere.

5. Every route must have validation.

6. Every controller must use try/catch or asyncHandler.

7. Use centralized error handling.

8. Use JWT Authentication.

9. Hash passwords using bcrypt.

10. Store secrets only in .env.

11. Create reusable services.

12. No business logic inside routes.

13. Follow existing folder structure.

14. Write scalable code.

15. Mobile-first API design.

16. Return consistent JSON responses.

17. Every feature must be Postman tested.

18. No breaking changes.

19. Add proper status codes.

20. Optimize for low-end devices.
